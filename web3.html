Web 3.0

A Web 3.0 serviu para organizar a massa de informação de acordo com o contexto e necessidade dos consumidores, levando em consideração localização, preferências, etc. E uma web mais portátil que aproxima cada vez mais o real e o virtual. A Web 3.0 procura converter grandes quantidades num formato mais interligado, semelhante a uma base de dados universal.
